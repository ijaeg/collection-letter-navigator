# Demo letters

Fictional letters used by the demo cases (FR-03 AC1, FR-03 AC3) and by the
Letter Check (FR-16).

Rules for every file here:

- Fictional names, addresses, IBANs, case numbers and customer numbers only.
  Nothing taken from a real letter.
- German text, as a real letter would be; the app redacts personal data before
  any LLM call (FR-16 AC2).
- At most 6,000 characters, the Letter Check input limit (FR-16 AC1).
- One `.txt` file per letter, named after its demo case.
